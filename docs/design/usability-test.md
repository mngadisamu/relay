# Sprint 4 Usability Test Results

## Overview
* **Dates:** November 17, 2026
* **Testers:** 4 participants (anonymous)
* **Scope:** End-to-end task flows covering request submission, staff replies, manager approvals, and flagged response reviews.

---

## Test Tasks & Metrics

1. **Submit a Request**
   * *Target workflow:* Create and submit a new staff request.
   * *Findings:* Completed smoothly by all participants. Clear labeling and fast navigation.

2. **Reply to a Request**
   * *Target workflow:* View a request thread and send a follow-up response.
   * *Findings:* Thread timestamps and visual distinction between staff and team messages worked as expected.

3. **Approve a Request**
   * *Target workflow:* Navigate to the manager view and approve/decline a pending ticket.
   * *Findings:* Approval milestones rendered correctly in the status history timeline.

4. **Find a Flagged Response**
   * *Target workflow:* Locate and review flagged content/notices.
   * *Findings:* In-app notices fallback and status pills provided clear status indicators without cognitive load.

---

## Actionable Takeaways
* Interface layout works well at both desktop and mobile widths.
* Status history timeline clearly communicates approval steps and timestamps in SAST.
