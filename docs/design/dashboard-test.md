# Dashboard 10-second test (S2-23)

Owner: Mihlali · Story S2-23 · Status: **protocol written, test not yet run**

The test checks that a manager can tell what the dashboard says within 10 seconds, without help. It is run with two colleagues from outside the Relay team.

## How to run it

1. Open `/manager/dashboard` on the live site, signed in as the test manager. Use the default view (last 30 days, all departments).
2. Show the colleague the screen for **10 seconds**, then hide it.
3. Ask: "In one or two sentences, what does this tell a manager?" Write their answer word for word.
4. Ask: "What is the most important number, and is it going up or down?" Write the answer word for word.
5. Ask: "Is there anything you couldn't understand?" Write the answer word for word.
6. Repeat with the IT department filter, so the second view is different.

Do not explain the screen before the 10 seconds. Do not correct wrong answers during the test.
