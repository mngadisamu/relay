## 4. Visual Design & Branding Standards
* **Color Palette:**
  * **Primary Brand:** Kopano Freight Navy (`#1E293B`)
  * **Accent/Highlight:** Relay Blue (`#2563EB`)
  * **Background Cards:** Off-white (`#F8FAFC`)
* **Typography:** System Inter / Sans-serif for web UI and standard Helvetica for PDF rendering.
* **Header:** Relay logo placed top-left; document title and metadata top-right.
* **Footer:** Generation timestamp (SAST) and confidentiality disclaimer.

## 5. Compliance & Privacy Rules
* **No PII:** Oldest open tickets display Reference ID, Subject line, and Age only — customer/staff names are excluded to prevent privacy leaks in exported PDFs[cite: 8].
* **Transparency:** Section 2 must render the standardized `AiNote` component[cite: 8].
